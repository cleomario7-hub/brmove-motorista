# BRMove - App do motorista (Android)
Mesmo processo do app do cliente: novo repositório no GitHub com `www/index.html`
e `.github/workflows/main.yml`, depois rodar o Build APK na aba Actions.


## Navegação e contato

Na corrida ativa, o motorista pode abrir o destino no **Google Maps** ou no **Waze**. O botão **Mensagens e contato** abre o chat com o cliente e oferece ligação telefônica e WhatsApp quando houver telefone cadastrado.
